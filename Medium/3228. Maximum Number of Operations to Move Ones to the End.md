# [3228. Maximum Number of Operations to Move Ones to the End](https://leetcode.com/problems/maximum-number-of-operations-to-move-ones-to-the-end)

## Description

You are given a binary string `s`.

You can perform the following operation on the string **any** number of times:

- Choose **any** index `i` from the string where `i + 1 < s.length` such that `s[i] == '1'` and `s[i + 1] == '0'`.
- Move the character `s[i]` to the **right** until it reaches the end of the string or another `'1'`. For example, for `s = "010010"`, if we choose `i = 1`, the resulting string will be `s = "0**001**10"`.

Return the **maximum** number of operations that you can perform.

**Example 1:**

**Input:** s = "1001101"  
**Output:** 4  
**Explanation:**  
We can perform the following operations:

- Choose index `i = 0`. The resulting string is `s = "**001**1101"`.
- Choose index `i = 4`. The resulting string is `s = "0011**01**1"`.
- Choose index `i = 3`. The resulting string is `s = "001**01**11"`.
- Choose index `i = 2`. The resulting string is `s = "00**01**111"`.

**Example 2:**

**Input:** s = "00111"  
**Output:** 0

**Constraints:**

- `1 <= s.length <= 10^5`
- `s[i]` is either `'0'` or `'1'`.

## My Solution

**JavaScript**

```js
// Approach: Single pass. The optimal strategy to MAXIMIZE the number of operations is to always
// move the left-most 1, opposite of the strategy to MINIMIZE the number of operations by always
// choosing the right-most 1. Every time we encounter a '1', increment a counter.
// When we encounter a '0' followed by a '1', we increment the maximum number of operations
// by the current count of '1's. This is because we know every single '1' in our current grouping of
// '1's will eventually pass the current group of '0's.
const maxOperations = (s) => {
  let numOps = 0;
  const n = s.length;
  let ones = 0;

  for (let i = 0; i < n; ++i) {
    if (s[i] === '1') ones++;
    // We found a zero following a one
    else if (i > 0 && s[i] === '0' && s[i - 1] === '1') {
      numOps += ones;
    }
  }

  return numOps;
};
```

```js
// Approach: Two passes, one to calculate the number of '10' pairs found, and then another
// to calculate the maximum number of operations. We observe that every time we encounter a '10', it
// can be moved once during that simulated turn. However, it can also be moved again in the future, after
// a '1' that comes after it is moved, thus freeing up space for it to be moved again. So by counting the number
// of times '10' occurs, we can move every occurrence of '10' once plus the number of '10' pairs AFTER this pair.
// If '1' occurs without a 0 after it, we cannot move the '1' during this turn, but it may be moved in the future.
const maxOperations = (s) => {
  let numOps = 0;
  let totalPairs = 0;

  // How many '10' pairs are there?
  for (let i = 0; i < s.length - 1; ++i) {
    if (s[i] === '1' && s[i + 1] === '0') {
      totalPairs++;
    }
  }

  for (let i = 0; i < s.length - 1; ++i) {
    // If we encounter a '10' pair, we decrement the pair count by 1.
    // The current '1' can be moved once now, and then an additional time
    // for each future '10' pairing still remaining.
    if (s[i] === '1' && s[i + 1] === '0') {
      totalPairs--; // This '10' contributed to totalPairs, so remove it before calculation
      numOps += totalPairs + 1;
    } else if (s[i] === '1') {
      // Otherwise, we cannot move '1' during this move, BUT it can still be moved
      // once for each future '10' pairing still remaining.
      numOps += totalPairs;
    }
  }

  return numOps;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N)            | O(1)             |
