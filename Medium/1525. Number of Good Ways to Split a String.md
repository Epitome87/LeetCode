# [1525. Number of Good Ways to Split a String](https://leetcode.com/problems/number-of-good-ways-to-split-a-string)

## Description

You are given a string `s`.

A split is called **good** if you can split `s` into two non-empty strings `sleft` and `sright` where their concatenation is equal to `s` (i.e., `sleft + sright = s`) and the number of distinct letters in `sleft` and `sright` is the same.

Return _the number of **good splits** you can make in `s`_.

**Example 1:**

**Input:** s = "aacaba"  
**Output:** 2  
**Explanation:** There are 5 ways to split `"aacaba"` and 2 of them are good.  
("a", "acaba") Left string and right string contains 1 and 3 different letters respectively.  
("aa", "caba") Left string and right string contains 1 and 3 different letters respectively.  
("aac", "aba") Left string and right string contains 2 and 2 different letters respectively (good split).  
("aaca", "ba") Left string and right string contains 2 and 2 different letters respectively (good split).  
("aacab", "a") Left string and right string contains 3 and 1 different letters respectively.

**Example 2:**

**Input:** s = "abcd"  
**Output:** 1  
**Explanation:** Split the string as follows ("ab", "cd").

**Constraints:**

- `1 <= s.length <= 10^5`
- `s` consists of only lowercase English letters.

## My Solution

**JavaScript**

```js
// Approach: O(1) space
const numSplits = (s) => {
  let result = 0;

  // Map to track char frequencies of the right side substring
  const rightFreq = new Map();
  for (const char of s) {
    rightFreq.set(char, rightFreq.get(char) + 1 || 1);
  }

  let rightUniqueCount = rightFreq.size;
  const leftSet = new Set(); // Can also use this to get left unique count

  for (let i = 0; i < s.length - 1; ++i) {
    const char = s[i];

    // Add current character to left side
    leftSet.add(char);

    // Remove current character from right side
    const newCount = rightFreq.get(char) - 1;
    if (newCount === 0)
      rightUniqueCount--; // Char gone from the right
    else rightFreq.set(char, newCount); // Char frequency reduced by 1

    // Do left side and right have equal uniques?
    if (leftSet.size === rightUniqueCount) {
      result++;
    }
  }

  return result;
};
```

```js
// Approach: Using a Set and uniques counter for both the left and right sides of each possible string.
const numSplits = (s) => {
  let result = 0;
  const uniquesLeftSet = new Set();
  const uniquesRightSet = new Set();
  const uniquesLeftCount = Array(s.length).fill(0);
  const uniquesRightCount = Array(s.length).fill(0);

  for (let i = 0; i < s.length; ++i) {
    uniquesLeftSet.add(s[i]);
    uniquesLeftCount[i] = uniquesLeftSet.size;
  }

  for (let i = s.length - 1; i >= 0; --i) {
    uniquesRightSet.add(s[i]);
    uniquesRightCount[i] = uniquesRightSet.size;
  }

  for (let i = 0; i < s.length - 1; ++i) {
    if (uniquesLeftCount[i] === uniquesRightCount[i + 1]) {
      ++result;
    }
  }

  return result;
};
```

```js
// Approach: Brute-Force (Time Limit Exceeded)
const numSplits = (s) => {
  let result = 0;

  for (let i = 1; i < s.length; ++i) {
    const left = s.slice(0, i);
    const right = s.slice(i);
    const seenLeft = new Set(left);
    const seenRight = new Set(right);

    if (seenLeft.size === seenRight.size) {
      ++result;
    }
  }

  return result;
};
```
