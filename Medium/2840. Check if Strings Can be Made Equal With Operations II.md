# [2840. Check if Strings Can be Made Equal With Operations II](https://leetcode.com/problems/check-if-strings-can-be-made-equal-with-operations-ii)

## Description

You are given two strings `s1` and `s2`, both of length `n`, consisting of **lowercase** English letters.

You can apply the following operation on **any** of the two strings **any** number of times:

- Choose any two indices `i` and `j` such that `i < j` and the difference `j - i` is **even**, then **swap** the two characters at those indices in the string.

Return `true` _if you can make the strings_ `s1` _and_ `s2` *equal, and* `false` _otherwise_.

**Example 1:**

**Input:** s1 = "abcdba", s2 = "cabdab"  
**Output:** true  
**Explanation:** We can apply the following operations on s1:

- Choose the indices i = 0, j = 2. The resulting string is s1 = "cbadba".
- Choose the indices i = 2, j = 4. The resulting string is s1 = "cbbdaa".
- Choose the indices i = 1, j = 5. The resulting string is s1 = "cabdab" = s2.

**Example 2:**

**Input:** s1 = "abe", s2 = "bea"  
**Output:** false  
**Explanation:** It is not possible to make the two strings equal.

**Constraints:**

- `n == s1.length == s2.length`
- `1 <= n <= 10^5`
- `s1` and `s2` consist only of lowercase English letters.

## My Solution

**JavaScript**

```js
/* Approach: Note that we can only swap characters at the same parity, i.e
if character a starts at an odd index, it can only be swapped to other odd indices.
Therefore, we just have to ensure the frequency of characters at odd indices in s1 matches
the frequency of characters at odd indices in s2, and the same for even indices.
We can combine this into a single freq counter by storing even index counts at from freq[0] to
freq[25], and odd from freq[26] to freq[51]. */
const checkStrings = (s1, s2) => {
  const freq = Array(52).fill(0);

  for (let i = 0; i < s1.length; ++i) {
    // Use the parity to determine which half of the freq counter char belongs to
    const offset = (i % 2) * 26;
    freq[s1.charCodeAt(i) - 97 + offset]++;
    freq[s2.charCodeAt(i) - 97 + offset]--;
  }

  // If the frequencies from each string cancelled each other out,
  // we can form a valid solution with swaps.
  for (const char of freq) {
    if (char !== 0) return false;
  }

  return true;
};
```

| --------------- | ---------------- |
| O(N)            | O(1)             |
