# [2244. Minimum Rounds to Complete All Tasks](https://leetcode.com/problems/minimum-rounds-to-complete-all-tasks)

## Description

You are given a **0-indexed** integer array `tasks`, where `tasks[i]` represents the difficulty level of a task. In each round, you can complete either 2 or 3 tasks of the **same difficulty level**.

Return _the **minimum** rounds required to complete all the tasks, or_ `-1` _if it is not possible to complete all the tasks._

**Example 1:**

**Input:** tasks = [2,2,3,3,2,4,4,4,4,4]  
**Output:** 4  
**Explanation:** To complete all the tasks, a possible plan is:

- In the first round, you complete 3 tasks of difficulty level 2.
- In the second round, you complete 2 tasks of difficulty level 3.
- In the third round, you complete 3 tasks of difficulty level 4.
- In the fourth round, you complete 2 tasks of difficulty level 4.  
  It can be shown that all the tasks cannot be completed in fewer than 4 rounds, so the answer is 4.

**Example 2:**

**Input:** tasks = [2,3,3]  
**Output:** -1  
**Explanation:** There is only 1 task of difficulty level 2, but in each round, you can only complete either 2 or 3 tasks of the same difficulty level. Hence, you cannot complete all the tasks, and the answer is -1.

**Constraints:**

- `1 <= tasks.length <= 105`
- `1 <= tasks[i] <= 109`

**Note:** This question is the same as [2870: Minimum Number of Operations to Make Array Empty.](https://leetcode.com/problems/minimum-number-of-operations-to-make-array-empty/description/)

## My Solution

**JavaScript**

```js
// The optimized approach is to always complete tasks 3 at a time.
// If a task count divides evenly by 3, that task requires t / 3 rounds.
// If t % 3 === 1, we are left with some groups of 3 tasks and a single group of 1.
// To form a valid round, we transfer a task from one of the groups of 3 over to that
// single group, giving (t // 3) + 1 rounds. Similarly, if t % 3 === 2, we are left with
// some groups of 3 tasks and a group of 2 tasks, which is valid. This is also (t // 3) + 1 rounds!
const minimumRounds = (tasks) => {
  let result = 0;

  // Count the frequency of each task
  const counts = new Map();
  for (const task of tasks) {
    counts.set(task, counts.get(task) + 1 || 1);
  }

  for (let [_, count] of counts) {
    // We have to do tasks in groups of 3 or 2
    if (count === 1) return -1;
    // If the task count divides by 3, we put them in count / 3 groups
    if (count % 3 === 0) result += count / 3;
    // Otherwise, we need only one extra group after the groups of 3
    else result += Math.floor(count / 3) + 1;
  }

  return result;
};
```
