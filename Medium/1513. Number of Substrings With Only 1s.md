# [1513. Number of Substrings With Only 1s](https://leetcode.com/problems/number-of-substrings-with-only-1s)

## Description

Given a binary string `s`, return _the number of substrings with all characters_ `1`_'s_. Since the answer may be too large, return it modulo `109 + 7`.

OriginalPython3**Example 1:**

**Input:** s = "0110111"  
**Output:** 9  
**Explanation:** There are 9 substring in total with only 1's characters.  
"1" -> 5 times.  
"11" -> 3 times.  
"111" -> 1 time.

**Example 2:**

**Input:** s = "101"  
**Output:** 2  
**Explanation:** Substring "1" is shown 2 times in s.

**Example 3:**

**Input:** s = "111111"  
**Output:** 21  
**Explanation:** Each substring contains only 1's characters.

**Constraints:**

- `1 <= s.length <= 10^5`
- `s[i]` is either `'0'` or `'1'`.

## My Solution

**JavaScript**

```js
// Approach: Observe that for a group of 1s, we can calculate how
// many substrings contribute to the result using Guassian Sum: A single
// '1' contributes 1, two 1's contributes 2 more, three 1's contributes 3 more,
// and so on. A single group of n 1's, then, contributes 1 + 2 + 3 ... + n!
const numSub = (s) => {
  const mod = 1_000_000_007;
  let result = 0;
  let numOnes = 0;

  for (let i = 0; i < s.length; ++i) {
    if (s[i] === '0') {
      result += (((numOnes + 1) * numOnes) / 2) % mod;
      numOnes = 0;
    } else numOnes++;
  }

  // If the str ended in 1, we still have one last grouping to count
  result += (((numOnes + 1) * numOnes) / 2) % mod;

  return result % mod;
};
```
