# [201. Bitwise AND of Numbers Range](https://leetcode.com/problems/bitwise-and-of-numbers-range)

## Description

Given two integers `left` and `right` that represent the range `[left, right]`, return _the bitwise AND of all numbers in this range, inclusive_.

**Example 1:**

**Input:** left = 5, right = 7  
**Output:** 4

**Example 2:**

**Input:** left = 0, right = 0  
**Output:** 0

**Example 3:**

**Input:** left = 1, right = 2147483647  
**Output:** 0

**Constraints:**

- `0 <= left <= right <= 2^31 - 1`

## My Solution

**JavaScript**

```js
// Approach: Using Brian Kernighan's algorithm, we clear the rightmost set bit until
// right becomes equal to or less than left. At this point right stores the common set prefix
// of right and left.
const rangeBitwiseAnd = (left, right) => {
  while (right > left) {
    right &= right - 1;
  }
  return right;
};
```

```js
const rangeBitwiseAnd = (left, right) => {
  let shiftCount = 0;

  // Right-shift each number until they share a common prefix, i.e for left = 12 and right = 15
  // we have 1100 and 1111. After two shifts, left became 11 and right became 11.
  while (left < right) {
    left >>= 1;
    right >>= 1;
    shiftCount++;
  }

  // At this point, shiftCount is how many bits were removed from the right side because they
  // were in positions that guaranteed they'd flip to 0 at least once, and thus any amount
  // of AND'ing to that bit would stay 0.

  // Here, left contains the "stable" prefix of bits. To get it back to its correct bit
  // place, we need to shift it back left the same amount we shifted it right to reach it.
  return left << shiftCount;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(Log(right))   | O(1)             |

```js
// Approach: Brute-Force (Time Limit Exceeded, probably!)
const rangeBitwiseAnd = (left, right) => {
  let result = 0;

  for (let bit = 0; bit < 32; ++bit) {
    let allOnes = true;
    for (let i = left; i <= right; ++i) {
      if (((i >> bit) & 1) === 0) {
        allOnes = false;
        break;
      }
    }
    if (allOnes) {
      result |= 1 << bit;
    }
  }

  return result;
};
```

| Time Complexity         | Space Complexity |
| ----------------------- | ---------------- |
| O(32 \* (right - left)) | O(1)             |
