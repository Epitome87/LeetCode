# [3084. Count Substrings Starting and Ending with Given Character](https://leetcode.com/problems/count-substrings-starting-and-ending-with-given-character)

## Description

You are given a string `s` and a character `c`. Return _the total number of substrings of_ `s` _that start and end with_ `c`_._

**Example 1:**

**Input:** s = "abada", c = "a"  
**Output:** 6  
**Explanation:** Substrings starting and ending with `"a"` are: `"**a**bada"`, `"**aba**da"`, `"**abada**"`, `"ab**a**da"`, `"ab**ada**"`, `"abad**a**"`.

**Example 2:**

**Input:** s = "zzz", c = "z"  
**Output:** 6  
**Explanation:** There are a total of `6` substrings in `s` and all start and end with `"z"`.

**Constraints:**

- `1 <= s.length <= 10^5`
- `s` and `c` consist only of lowercase English letters.

## My Solution

**JavaScript**

```js
/* Observe that in the two test cases, there are 3 occurrences of the char c,
but the input strings are vastly different. This is perhaps a hint that we can
use the count of c and derive some sort of mathematical formula. Observe:
Count 1 = 1 substrings
Count 2 = 2 + 1 substrings
Count 3 = 3 + 2 + 1 substrings
Count 4 = 4 + 3 + 2 + 1 substrings
I.e, a count of n is the sum of the first n natural numbers.
This is n * (n + 1) / 2 */
const countSubstrings = (s, c) => {
  let charCount = 0;

  for (const char of s) {
    if (char === c) ++charCount;
  }

  return (charCount * (charCount + 1)) / 2;
};
```

```js
// Approach: Using a running prefix to pair each occurrence of c with every other
// occurrences that appeared before it.
const countSubstrings = (s, c) => {
  let result = 0;
  let charCount = 0;

  for (const char of s) {
    if (char === c) {
      charCount++;
      result += charCount;
    }
  }

  return result;
};
```

```js
// Approach: Using a prefix array that represents how frequently character c occurs by index i.
const countSubstrings = (s, c) => {
  let result = 0;
  const n = s.length;
  const prefix = new Array(n);
  for (let i = 0; i < n; ++i) {
    prefix[i] = (prefix[i - 1] || 0) + (s[i] === c);
  }

  for (let i = 0; i < n; ++i) {
    if (s[i] === c) {
      // This char on its own forms a substring starting and ending with c
      ++result;

      // How many occurrences of char occur after this one?
      // Each of these can form a different substring with this char
      result += prefix[n - 1] - prefix[i];
    }
  }

  return result;
};
```

| --------------- | ---------------- |
| O(N)            | O(N)             |
