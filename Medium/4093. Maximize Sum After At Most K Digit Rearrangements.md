# [4093. Maximize Sum After At Most K Digit Rearrangements](https://leetcode.com/problems/maximize-sum-after-at-most-k-digit-rearrangements)

## Description

You are given an integer array `nums` of length `n` and an integer `k`.

In one operation, you may choose any element of `nums` and **rearrange** its decimal digits in any order to form a new integer.

Return the **maximum** possible sum of the array after performing **at most** `k` operations.

**Example 1:**

**Input:** nums = [123,45], k = 1  
**Output:** 366  
**Explanation:**

- We choose `nums[0] = 123` and rearrange its digits to form 321.
- The array becomes `[321, 45]`. Thus, the total sum is `321 + 45 = 366`.

**Example 2:**

**Input:** nums = [102,90,14], k = 2  
**Output:** 341  
**Explanation:**

- We choose `nums[0] = 102` and rearrange its digits to form 210.
- We choose `nums[2] = 14` and rearrange its digits to form 41.
- The array becomes `[210, 90, 41]`. Thus, the total sum is `210 + 90 + 41 = 341`.

**Constraints:**

- `1 <= n == nums.length <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= n`

## My Solution

**JavaScript**

```js
// Approach: Avoiding string manipulation
const maximizeSum = (nums, k) => {
  const maxValue = (n) => {
    let result = 0;
    const digitCount = Array(10).fill(0);

    while (n > 0) {
      const digit = n % 10;
      digitCount[digit]++;
      n = Math.floor(n / 10);
    }

    for (let i = 9; i >= 0; --i) {
      for (let j = 0; j < digitCount[i]; ++j) {
        result = result * 10 + i;
      }
    }

    return result;
  };

  let sum = 0;
  const deltas = [];

  for (const num of nums) {
    sum += num;
    const delta = maxValue(num) - num;
    if (delta > 0) deltas.push(delta);
  }

  // Sort deltas, descending
  deltas.sort((a, b) => b - a);

  // We want to use the first k gains to maximize sum
  for (let i = 0; i < Math.min(deltas.length, k); ++i) {
    sum += deltas[i];
  }

  return sum;
};
```

```js
// Approach: For each number, rearrange it in a way that maximizes it (i.e sort in descending string order).
// Determine which rearrangements lead to a greater number than the original, and track that difference.
// Finally, add the kth largest differences to the total sum.
const maximizeSum = (nums, k) => {
  const rearrange = (n) =>
    Number(
      `${n}`
        .split('')
        .sort((a, b) => b.localeCompare(a))
        .join(''),
    );

  let sum = 0;
  const deltas = [];

  for (const num of nums) {
    sum += num;
    const delta = rearrange(num) - num;
    if (delta > 0) deltas.push(delta);
  }

  // Sort deltas, descending
  deltas.sort((a, b) => b - a);

  // We want to use the first k gains to maximize sum
  for (let i = 0; i < Math.min(deltas.length, k); ++i) {
    sum += deltas[i];
  }

  return sum;
};
```
