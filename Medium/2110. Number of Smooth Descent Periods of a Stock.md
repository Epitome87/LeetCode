# [2110. Number of Smooth Descent Periods of a Stock](https://leetcode.com/problems/number-of-smooth-descent-periods-of-a-stock)

## Description

You are given an integer array `prices` representing the daily price history of a stock, where `prices[i]` is the stock price on the `ith` day.

A **smooth descent period** of a stock consists of **one or more contiguous** days such that the price on each day is **lower** than the price on the **preceding day** by **exactly** `1`. The first day of the period is exempted from this rule.

Return _the number of **smooth descent periods**_.

**Example 1:**

**Input:** prices = [3,2,1,4]  
**Output:** 7  
**Explanation:** There are 7 smooth descent periods:  
[3], [2], [1], [4], [3,2], [2,1], and [3,2,1]  
Note that a period with one day is a smooth descent period by the definition.

**Example 2:**

**Input:** prices = [8,6,7,7]  
**Output:** 4  
**Explanation:** There are 4 smooth descent periods: [8], [6], [7], and [7]  
Note that [8,6] is not a smooth descent period as 8 - 6 ≠ 1.

**Example 3:**

**Input:** prices = [1]  
**Output:** 1  
**Explanation:** There is 1 smooth descent period: [1]

**Constraints:**

- `1 <= prices.length <= 10^5`
- `1 <= prices[i] <= 10^5`

## My Solution

**JavaScript**

```js
// Approach: Counting current streak. We observe that in the Two Pointer approach
// we always just reset left pointer to the right. This can typically be substituted
// with a simple streak / counter.
const getDescentPeriods = (prices) => {
  let result = 1; // We are guaranteed at least the 1st day
  let streak = 1; // And the first day is its own streak

  // Start at day 2, as we know day 1 was a streak of 1 already
  for (let i = 1; i < prices.length; ++i) {
    if (prices[i] === prices[i - 1] - 1) {
      streak++; // Descent continued, streak grows by 1
    } else streak = 1; // Descent broke; streak is just today

    // Add all subarrays ending at this specific day
    result += streak;
  }

  return result;
};
```

| --------------- | ---------------- |
| O(N)            | O(N)             |

```js
// Approach: Two Pointer
const getDescentPeriods = (prices) => {
  let result = 0;
  let left = 0;

  for (let right = 0; right < prices.length; ++right) {
    // If we are past the first day AND the descent is broken
    if (right > 0 && prices[right] !== prices[right - 1] - 1) {
      // Close the left point to the right's current position
      left = right;
    }

    // The number of new valid subarrays ending at 'right' is always
    // the size of the current window, even for subarrays of length 1.
    result += right - left + 1;
  }

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N)            | O(1)             |
