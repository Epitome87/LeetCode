# [1721. Swapping Nodes in a Linked List](https://leetcode.com/problems/swapping-nodes-in-a-linked-list)

## Description

You are given the `head` of a linked list, and an integer `k`.

Return _the head of the linked list after **swapping** the values of the_ `kth` _node from the beginning and the_ `kth` _node from the end (the list is **1-indexed**)._

**Example 1:**

![](https://assets.leetcode.com/uploads/2020/09/21/linked1.jpg)

**Input:** head = [1,2,3,4,5], k = 2  
**Output:** [1,4,3,2,5]

**Example 2:**

**Input:** head = [7,9,6,6,7,8,3,0,9,5], k = 5  
**Output:** [7,9,6,6,8,7,3,0,9,5]

**Constraints:**

- The number of nodes in the list is `n`.
- `1 <= k <= n <= 10^5`
- `0 <= Node.val <= 100`

## My Solution

**JavaScript**

```js
const swapNodes = (head, k) => {
  // We'll need a slow and fast node for traversal
  let slow = head;
  let fast = head;

  // And a first and second node to track the two kth nodes
  let first = head;
  let second = head;

  // Start the fast node (k - 1) positions in front of the slow node
  for (let i = 0; i < k - 1; ++i) {
    fast = fast.next;
  }

  // Remember the kth node from the start
  first = fast;

  // Traverse until end of list, at which point slow points to the kth node from end
  while (fast.next) {
    slow = slow.next;
    fast = fast.next;
  }

  // Remember the kth node from the end
  second = slow;

  // Swap the two tracked nodes
  [first.val, second.val] = [second.val, first.val];

  // And finally, return the initial head
  return head;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N)            | O(1)             |

```js
// Approach: Also a slow and fast pointer basically, but a little more concise.
const swapNodes = (head, k) => {
  let node1 = null;
  let node2 = null;
  let p = head;

  while (p) {
    --k;
    if (node2 !== null) node2 = node2.next;
    if (k === 0) {
      node1 = p;
      node2 = head;
    }
    p = p.next;
  }

  [node1.val, node2.val] = [node2.val, node1.val];

  return head;
};
```
