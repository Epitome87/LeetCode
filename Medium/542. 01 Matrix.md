# [542. 01 Matrix](https://leetcode.com/problems/01-matrix)

## Description

Given an `m x n` binary matrix `mat`, return _the distance of the nearest_ `0` _for each cell_.

The distance between two cells sharing a common edge is `1`.

**Example 1:**

![](https://assets.leetcode.com/uploads/2021/04/24/01-1-grid.jpg)

**Input:** mat = [[0,0,0],[0,1,0],[0,0,0]]  
**Output:** [[0,0,0],[0,1,0],[0,0,0]]

**Example 2:**

![](https://assets.leetcode.com/uploads/2021/04/24/01-2-grid.jpg)

**Input:** mat = [[0,0,0],[0,1,0],[1,1,1]]  
**Output:** [[0,0,0],[0,1,0],[1,2,1]]

**Constraints:**

- `m == mat.length`
- `n == mat[i].length`
- `1 <= m, n <= 10^4`
- `1 <= m * n <= 10^4`
- `mat[i][j]` is either `0` or `1`.
- There is at least one `0` in `mat`.

**Note:** This question is the same as 1765: [https://leetcode.com/problems/map-of-highest-peak/](https://leetcode.com/problems/map-of-highest-peak/description/)

## My Solution

**JavaScript**

```js
// Approach: BFS on 0 cells
const updateMatrix = (mat) => {
  const rows = mat.length;
  const cols = mat[0].length;
  const result = Array.from({ length: rows }, () => Array(cols).fill(Infinity));
  const dirs = [
    [1, 0],
    [-1, 0],
    [0, 1],
    [0, -1],
  ];
  const queue = [];

  // Fill queue with all the 0's, setting their distance to 0
  for (let r = 0; r < rows; ++r) {
    for (let c = 0; c < cols; ++c) {
      if (mat[r][c] === 0) {
        result[r][c] = 0;
        queue.push([r, c]);
      }
    }
  }

  let head = 0;
  while (head < queue.length) {
    const [r, c] = queue[head++];

    for (const [dr, dc] of dirs) {
      const nr = dr + r;
      const nc = dc + c;

      // Check if neighbor is valid and if we found a shorter path to it
      if (nr >= 0 && nr < rows && nc >= 0 && nc < cols) {
        if (result[nr][nc] > result[r][c] + 1) {
          result[nr][nc] = result[r][c] + 1;
          queue.push([nr, nc]);
        }
      }
    }
  }

  return result;
};
```

| --------------- | ---------------- |
