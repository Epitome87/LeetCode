# [386. Lexicographical Numbers](https://leetcode.com/problems/lexicographical-numbers)

## Description

Given an integer `n`, return all the numbers in the range `[1, n]` sorted in lexicographical order.

You must write an algorithm that runs in `O(n)` time and uses `O(1)` extra space. 

**Example 1:**

**Input:** n = 13  
**Output:** [1,10,11,12,13,2,3,4,5,6,7,8,9]

**Example 2:**

**Input:** n = 2  
**Output:** [1,2]

**Constraints:**

- `1 <= n <= 5 * 10^4`

## My Solution

**JavaScript**

```js
// Approach: Iterative. When possible, we add 0's to the current number, as keeping the
// same digits but adding a 0 would be lexicographically smaller than adding a 1. Otherwise
// we add 1's, except when doing so would put us out of range or the number ends in a 9. In these
// scenarios, we backtrack by removing the right-most digit, then increment by 1.
// Example: n is 300 and current number is 199; if we simply add 1 we will be at 200, but we need to
// add 2 first, as well as 20. So we backtrack until the last digit is not 9, i.e back to 1. We then
// add 1, putting us appropriately back to 2. At this point, we have the range to add a 0 to 2 rather than
// simply increment it by 1, so our next number is set to 20 rather than 2 + 1 = 3.
const lexicalOrder = (n) => {
  const result = [];
  let curNum = 1;

  for (let i = 0; i < n; ++i) {
    result.push(curNum);

    // Can we add a 0 to the number and still be within range? If so,
    // that would be lexicographically smaller than adding 1
    if (curNum * 10 <= n) curNum *= 10;
    else {
      // Else we should just add 1, except...
      // While the number ends in a 9, we have to backtrack.
      // Similarly if adding 1 would put us out of range.
      while (curNum % 10 === 9 || curNum >= n) {
        curNum = Math.floor(curNum / 10);
      }
      curNum++; // Add once after any potential backtracking
    }
  }

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N)            | O(1)             |
