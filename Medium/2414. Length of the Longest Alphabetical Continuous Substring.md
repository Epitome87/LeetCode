# [2414. Length of the Longest Alphabetical Continuous Substring](https://leetcode.com/problems/length-of-the-longest-alphabetical-continuous-substring)

## Description

An **alphabetical continuous string** is a string consisting of consecutive letters in the alphabet. In other words, it is any substring of the string `"abcdefghijklmnopqrstuvwxyz"`.

- For example, `"abc"` is an alphabetical continuous string, while `"acb"` and `"za"` are not.

Given a string `s` consisting of lowercase letters only, return the _length of the **longest** alphabetical continuous substring._

**Example 1:**

**Input:** s = "abacaba"  
**Output:** 2  
**Explanation:** There are 4 distinct continuous substrings: "a", "b", "c" and "ab".  
"ab" is the longest continuous substring.

**Example 2:**

**Input:** s = "abcde"  
**Output:** 5  
**Explanation:** "abcde" is the longest continuous substring.

**Constraints:**

- `1 <= s.length <= 10^5`
- `s` consists of only English lowercase letters.

## My Solution

**JavaScript**

```js
// Approach: Streak counting. Observe that in the sliding window technique,
// a breaking of the current streak meant sliding the left pointer all the way to
// the right, which consequently also resets the current substring length. With these
// observations in mind, we can skip the left pointer entirely, and instead explicitely
// keep track of and reset a streak counter.
const longestContinuousSubstring = (s) => {
  let maxLength = 1;
  let curLength = 1;

  for (let i = 1; i < s.length; ++i) {
    if (s[i].charCodeAt() === s[i - 1].charCodeAt() + 1) {
      ++curLength;
      maxLength = Math.max(maxLength, curLength);
    } else curLength = 1;
  }

  return maxLength;
};
```

```js
// Approach: Sliding Window
const longestContinuousSubstring = (s) => {
  let result = 1;
  let left = 0;

  for (let right = 1; right < s.length; ++right) {
    const prevCode = s[right - 1].charCodeAt();
    const code = s[right].charCodeAt();

    if (code !== prevCode + 1) left = right;
    else result = Math.max(result, right - left + 1);
  }

  return result;
};
```

```js
// Approach: Brute-Force
const longestContinuousSubstring = (s) => {
  let result = 1;
  let count = 1;

  for (let i = 0; i < s.length; ++i) {
    for (let j = i + 1; j < s.length; ++j) {
      const prevCode = s[j - 1].charCodeAt();
      const code = s[j].charCodeAt();
      if (code !== prevCode + 1) {
        count = 1;
        break;
      } else {
        result = Math.max(result, j - i + 1);
      }
    }
  }

  return result;
};
```
