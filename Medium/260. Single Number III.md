# [260. Single Number III](https://leetcode.com/problems/single-number-iii)

## Description

Given an integer array `nums`, in which exactly two elements appear only once and all the other elements appear exactly twice. Find the two elements that appear only once. You can return the answer in **any order**.

You must write an algorithm that runs in linear runtime complexity and uses only constant extra space.

**Example 1:**

**Input:** nums = [1,2,1,3,2,5]  
**Output:** [3,5]  
**Explanation:** [5, 3] is also a valid answer.

**Example 2:**

**Input:** nums = [-1,0]  
**Output:** [-1,0]

**Example 3:**

**Input:** nums = [0,1]  
**Output:** [1,0]

**Constraints:**

- `2 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- Each integer in `nums` will appear twice, only two integers will appear once.

## My Solution

**JavaScript**

```js
const singleNumber = (nums) => {
  let xorAll = 0;

  for (const num of nums) xorAll ^= num;

  // Isolate right-most set bit, i.e 6 (0110) becomes 0010
  const diffBit = xorAll & -xorAll; // Or = xorAll ^ (xorAll & (xorAll - 1))

  // Essentially, create buckets a and b. a will hold numbers that have their
  // right-most set bit the same as diffBit, while b will be the opposite.
  // In the end, XOR all elements in bucket a against one another will cancel out
  // duplicates, leaving just the single unique number that had a 1 in the right-most
  // set bit. The same for b -- it leaves the unique number that had 0 in that bit!
  let a = 0;
  let b = 0;

  for (const num of nums) {
    if (num & diffBit) a ^= num;
    else b ^= num;
  }

  return [a, b];
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N)            | O(1)             |
