# [477. Total Hamming Distance](https://leetcode.com/problems/total-hamming-distance)

## Description

The [Hamming distance](https://en.wikipedia.org/wiki/Hamming_distance) between two integers is the number of positions at which the corresponding bits are different.

Given an integer array `nums`, return _the sum of **Hamming distances** between all the pairs of the integers in_ `nums`.

OriginalJavaScript**Example 1:**

**Input:** nums = [4,14,2]  
**Output:** 6  
**Explanation:** In binary representation, the 4 is 0100, 14 is 1110, and 2 is 0010 (just
showing the four bits relevant in this case).  
The answer will be:  
HammingDistance(4, 14) + HammingDistance(4, 2) + HammingDistance(14, 2) = 2 + 2 + 2 = 6.

**Example 2:**

**Input:** nums = [4,14,4]  
**Output:** 4

**Constraints:**

- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^9`
- The answer for the given input will fit in a **32-bit** integer.

## My Solution

**JavaScript**

```js
// Approach: We can avoid pairing every number with one another one-by one. Instead,
// run through each bit and check all numbers at once. If we count the number of 0s and 1s
// that occur in all the numbers at that bit position, we can determine the hamming distance
// for that bit position using math. After iterating through all 32 bit positions, we have
// the total hamming distance!
const totalHammingDistance = (nums) => {
  let result = 0;

  for (let i = 0; i < 32; ++i) {
    let zeros = 0;
    let ones = 0;

    for (let num of nums) {
      if ((num >> i) & 1) ones++;
      else zeros++;
    }

    // Each 0 paired with each 1 at this bit position contributes 1 to the distance
    result += zeros * ones;
  }

  return result;
};
```

| --------------- | ---------------- |
| O(N)            | O(1)             |

```js
// Approach: Brute-Force (Probably Time Limit Exceeded)
const totalHammingDistance = (nums) => {
  const hammingDistance = (a, b) => {
    let distance = 0;
    for (let i = 0; i < 32; ++i) {
      distance += (a & 1) ^ (b & 1);
      a >>= 1;
      b >>= 1;
    }
    return distance;
  };

  let result = 0;

  for (let i = 0; i < nums.length; ++i) {
    for (let j = i + 1; j < nums.length; ++j) {
      result += hammingDistance(nums[i], nums[j]);
    }
  }

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N^2)          | O(1)             |
