# [2799. Count Complete Subarrays in an Array](https://leetcode.com/problems/count-complete-subarrays-in-an-array)

## Description

You are given an array `nums` consisting of **positive** integers.

We call a subarray of an array **complete** if the following condition is satisfied:

- The number of **distinct** elements in the subarray is equal to the number of distinct elements in the whole array.

Return _the number of **complete** subarrays_.

A **subarray** is a contiguous non-empty part of an array.

**Example 1:**

**Input:** nums = [1,3,1,2,2]  
**Output:** 4  
**Explanation:** The complete subarrays are the following: [1,3,1,2], [1,3,1,2,2], [3,1,2] and [3,1,2,2].

**Example 2:**

**Input:** nums = [5,5,5,5]  
**Output:** 10  
**Explanation:** The array consists only of the integer 5, so any subarray is complete. The number of subarrays that we can choose is 10.

**Constraints:**

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 2000`

## My Solution

**JavaScript**

```js
// Approach: Sliding Window
const countCompleteSubarrays = (nums) => {
  let result = 0;
  const targetUniques = new Set(nums).size;
  const counts = new Map();
  let left = 0;

  for (const rightVal of nums) {
    // Expand the window
    counts.set(rightVal, (counts.get(rightVal) || 0) + 1);

    // Shrink window until it no longer holds all uniques
    while (counts.size === targetUniques) {
      const leftVal = nums[left];
      counts.set(leftVal, counts.get(leftVal) - 1);
      if (counts.get(leftVal) === 0) counts.delete(leftVal);
      ++left;
    }

    // Add all valid subarrays ending at the current right value
    // I.e if indices 2 to 6 formed a valid subarray, so must the subarray
    // from 0 to 6 and 1 to 6.
    result += left;
  }

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N)            | O(N)             |

```js
// Approach: Brute-Force
const countCompleteSubarrays = (nums) => {
  let result = 0;
  const fullUniques = new Set(nums);
  const subUniques = new Set();

  for (let i = 0; i < nums.length; ++i) {
    subUniques.clear();
    for (let j = i; j < nums.length; ++j) {
      subUniques.add(nums[j]);
      if (subUniques.size === fullUniques.size) {
        ++result;
      }
    }
  }

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N^2)          | O(N)             |
