# [3121. Count the Number of Special Characters II](https://leetcode.com/problems/count-the-number-of-special-characters-ii)

## Description

You are given a string `word`. A letter `c` is called **special** if it appears **both** in lowercase and uppercase in `word`, and **every** lowercase occurrence of `c` appears before the **first** uppercase occurrence of `c`.

Return the number of **special** letters in `word`.

**Example 1:**

**Input:** word = "aaAbcBC"  
**Output:** 3  
**Explanation:** The special characters are `'a'`, `'b'`, and `'c'`.

**Example 2:**

**Input:** word = "abc"  
**Output:** 0  
**Explanation:** There are no special characters in `word`.

**Example 3:**

**Input:** word = "AbBCab"  
**Output:** 0  
**Explanation:** There are no special characters in `word`.

**Constraints:**

- `1 <= word.length <= 2 * 10^5`
- `word` consists of only lowercase and uppercase English letters.

## My Solution

**JavaScript**

```js
const numberOfSpecialChars = (word) => {
  let result = 0;

  // From 0-25, stores the last index of lowercase 'a' to 'z'
  // From 26-51, stores the first index of uppercase 'A' to 'Z'
  const indices = Array(52).fill(-1);

  for (let i = 0; i < word.length; ++i) {
    const charCode = word[i].charCodeAt();
    if (charCode >= 97) indices[charCode - 97] = i;
    else {
      if (indices[charCode - 65 + 26] === -1) {
        indices[charCode - 65 + 26] = i;
      }
    }
  }

  // From 'a' to 'z', see if it meets the "is special" requirements of 1) Occurring in both
  // lowercase and uppercase form and 2) All lowercase appearing before the first uppercase
  for (let char = 0; char < 26; ++char) {
    const lastIdxOfLower = indices[char];
    const firstIdxOfUpper = indices[char + 26];
    if (lastIdxOfLower !== -1 && firstIdxOfUpper !== -1 && lastIdxOfLower < firstIdxOfUpper) ++result;
  }

  return result;
};
```

```js
const numberOfSpecialChars = (word) => {
  let result = 0;
  const uniques = new Set(word.toLowerCase());

  for (const char of uniques) {
    if (isSpecial(char, word)) {
      result++;
    }
  }

  return result;
};

// Returns true if the character appears in both lowercase and uppercase in word,
// and if all occurrences of lowercases appear before the first uppercase.
const isSpecial = (char, word) => {
  const lowercaseCode = char.toLowerCase().charCodeAt();
  const uppercaseCode = char.toUpperCase().charCodeAt();

  let lastIndexOfLower = -1;
  let firstIndexOfUpper = -1;

  for (let i = 0; i < word.length; ++i) {
    if (word[i].charCodeAt() === lowercaseCode) lastIndexOfLower = i;
    else if (word[i].charCodeAt() === uppercaseCode) {
      if (firstIndexOfUpper === -1) firstIndexOfUpper = i;
    }
  }

  return lastIndexOfLower !== -1 && firstIndexOfUpper !== -1 && lastIndexOfLower < firstIndexOfUpper;
};
```
