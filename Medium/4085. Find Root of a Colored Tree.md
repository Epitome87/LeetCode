# [4085. Find Root of a Colored Tree](https://leetcode.com/problems/find-root-of-a-colored-tree)

## Description

You are given an undirected **tree** of `n` nodes labeled from `0` to `n - 1`, represented by a 2D integer array `edges` of length `n - 1`, where `edges[i] = [ui, vi]` indicates that there is an undirected edge between nodes `ui` and `vi`.

You are also given a string `colors` of length `n`, where `colors[i]` is one of `'R'`, `'B'`, or `'W'`, and denotes the color of node `i`.

A node chosen as **root** must satisfy both of the following **conditions** once the tree is oriented away from it:

1.  **Binary-tree property:** Every node has at most two children.
2.  **Layered color pattern:** All nodes at the same depth have the same color. Starting at depth 0, these colors follow one of the three repeating sequences:
    - `R → B → W → R → B → W → ...`
    - `B → W → R → B → W → R → ...`
    - `W → R → B → W → R → B → ...`

Return the **index** of any root that satisfies both conditions, or -1 if no such root exists.

A **tree** is a connected undirected graph with no cycles.

The **depth** of a node is the number of edges on the path from the root to that node. The root has depth 0. A **child** of a node is an adjacent node whose depth is one greater.

The **degree** of a node is the number of edges incident to it.

**Example 1:**

**Input:** edges = \[\[3,1\],\[3,2\],\[1,4\],\[2,0\]\], colors = "BRRWB"  
**Output:** 3  
**Explanation:**

![](https://assets.leetcode.com/uploads/2025/06/15/treee.jpg)

Rooting at node 3 gives each node at most two children and every edge advances to the next color in the cycle (`W → R → B`), so return 3.

**Example 2:**

**Input:** edges = \[\[0,1\],\[1,2\],\[2,3\]\], colors = "RBRB"  
**Output:** \-1  
**Explanation:**

![](https://assets.leetcode.com/uploads/2025/06/15/treee2.jpg)

No root satisfies the required color step on every edge, so return -1.

**Constraints:**

- `2 <= n <= 105`
- `edges.length == n - 1`
- `edges[i] = [ui, vi]`
- `0 <= ui, vi < n`
- `colors.length == n`
- `colors[i]` is one of `'R'`, `'B'`, `'W'`.
- The input graph is a tree and every node has degree at most three.

## My Solution

**JavaScript**

```js
// Approach: To be chosen as a root, a node must have <= 2 children, and no parent.
// To fulfill the color requirement, every connection starting from that selected node
// must be the next color in the R -> B -> W color cycle.
const findColoredRoot = (edges, colors) => {
  let root = -1;
  const n = colors.length;
  const numParent = Array(n).fill(0);
  const numChildren = Array(n).fill(0);
  const colorMap = { R: 0, B: 1, W: 2 };

  for (const [u, v] of edges) {
    const colorU = colorMap[colors[u]];
    const colorV = colorMap[colors[v]];

    // Adjacent nodes have the same color, meaning no node meets the requirements
    if (colorU === colorV) return -1;

    // To continue the color cycle, do we go from node U to V, or V to U?
    const nextColor = (colorU + 1) % 3;
    if (nextColor === colorV) {
      // U -> V
      numChildren[u]++;
      numParent[v]++;
    } else {
      // V -> U
      numChildren[v]++;
      numParent[u]++;
    }
  }

  // Iterate through each node, checking which one meets the requirements for a valid root
  for (let i = 0; i < n; ++i) {
    if (numChildren[i] > 2 || numParent[i] > 1) return -1; // Binary tree condition invalid
    if (numParent[i] === 0) {
      // Potential root candidate...
      if (root !== -1) return -1; // Unless we have more than 1 nodes with no parent
      root = i;
    }
  }

  return root;
};
```

```js
// Approach: Brute-Force BFS with some pruning. Try every edge, exploring it fully to see if it is a valid root candidate.
// (Time Limit Exceeded)
const findColoredRoot = (edges, colors) => {
  const n = colors.length;
  const colorMap = { R: 0, B: 1, W: 2 };

  // Create adjacency list
  const adj = Array(n)
    .fill(null)
    .map(() => []);

  for (const [u, v] of edges) {
    adj[u].push(v);
    adj[v].push(u);
  }

  // Pre-BFS pruning: A node must have degree <= 3 (2 children + 1 parent).
  for (let i = 0; i < n; ++i) {
    if (adj[i].length > 3) return -1;
  }

  for (let root = 0; root < n; ++root) {
    // Prune root: A root must have degree <= 2, since it has no parent (and <= 2 children)
    if (adj[root].length > 2) continue;

    // Prune neighbors based on color: Avoid BFS if immediate edges are invalid
    const expectedChildColor = (colorMap[colors[root]] + 1) % 3;
    const immediateNeighborsValid = adj[root].every((neighbor) => colorMap[colors[neighbor]] === expectedChildColor);
    if (!immediateNeighborsValid) continue;

    // After pruning, run O(1) pointer-based BFS on remaining candidates
    const queue = [root];
    let head = 0;
    const visited = Array(n).fill(false);
    visited[root] = true;
    let isValid = true;

    while (head < queue.length && isValid) {
      // const node = queue.shift();
      const node = queue[head++];
      let children = 0;

      for (const neighbor of adj[node]) {
        if (visited[neighbor]) continue;
        visited[neighbor] = true;
        children++;

        const nextColor = (colorMap[colors[node]] + 1) % 3;
        if (colorMap[colors[neighbor]] !== nextColor) {
          isValid = false;
          break;
        }

        queue.push(neighbor);
      }

      if (children > 2) isValid = false;
    }

    // If the tree was valid AND all nodes were used in this tree (i.e no islands)
    if (isValid && head === n) return root;
  }

  return -1;
};
```
