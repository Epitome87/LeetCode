# [1291. Sequential Digits](https://leetcode.com/problems/sequential-digits)

## Description

An integer has _sequential digits_ if and only if each digit in the number is one more than the previous digit.

Return a **sorted** list of all the integers in the range `[low, high]` inclusive that have sequential digits.

**Example 1:**

**Input:** low = 100, high = 300  
**Output:** [123,234]

**Example 2:**

**Input:** low = 1000, high = 13000  
**Output:** [1234,2345,3456,4567,5678,6789,12345]

**Constraints:**

- `10 <= low <= high <= 10^9`

## My Solution

**JavaScript**

```js
// Approach: Simply hard-code all the sequential numbers given
// the constraint range of the problem! Rather than iterating from low
// to high and checking if that number is in the hard-coded hash set, we
// iterate through the small hash set and see if the entry is within [low, high].
const sequentialDigits = (low, high) => {
  const result = [];
  const seqNums = new Set([
    12, 23, 34, 45, 56, 67, 78, 89, 123, 234, 345, 456, 567, 678, 789, 1234, 2345, 3456, 4567, 5678, 6789, 12345, 23456,
    34567, 45678, 56789, 123456, 234567, 345678, 456789, 1234567, 2345678, 3456789, 12345678, 23456789, 123456789,
  ]);

  for (const seqNum of seqNums) {
    if (seqNum >= low && seqNum <= high) {
      result.push(seqNum);
    }
  }

  return result;
};
```

```js
const sequentialDigits = (low, high) => {
  const result = [];

  for (let i = 1; i <= 9; ++i) {
    let num = i;

    for (let j = i + 1; j <= 9; ++j) {
      num = num * 10 + j;
      if (num > high) break;
      if (num >= low) result.push(num);
    }
  }

  return result.sort((a, b) => a - b);
};
```

```js
// Approach: Using a variable sliding window to take slices of '123456789' in
// ascending length order, so we avoid having to sort the results at the end.
const sequentialDigits = (low, high) => {
  const result = [];

  const digits = '123456789';
  const minLength = String(low).length;
  const maxLength = String(high).length;

  for (let length = minLength; length <= maxLength; ++length) {
    for (let start = 0; start <= 9 - length; ++start) {
      const num = Number(digits.slice(start, start + length));
      if (num >= low && num <= high) result.push(num);
    }
  }

  return result;
};
```
