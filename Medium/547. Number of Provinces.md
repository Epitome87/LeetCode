# [547. Number of Provinces](https://leetcode.com/problems/number-of-provinces)

## Description

There are `n` cities. Some of them are connected, while some are not. If city `a` is connected directly with city `b`, and city `b` is connected directly with city `c`, then city `a` is connected indirectly with city `c`.

A **province** is a group of directly or indirectly connected cities and no other cities outside of the group.

You are given an `n x n` matrix `isConnected` where `isConnected[i][j] = 1` if the `ith` city and the `jth` city are directly connected, and `isConnected[i][j] = 0` otherwise.

Return _the total number of **provinces**_.

**Example 1:**

![](https://assets.leetcode.com/uploads/2020/12/24/graph1.jpg)

**Input:** isConnected = [[1,1,0],[1,1,0],[0,0,1]]  
**Output:** 2

**Example 2:**

![](https://assets.leetcode.com/uploads/2020/12/24/graph2.jpg)

**Input:** isConnected = [[1,0,0],[0,1,0],[0,0,1]]  
**Output:** 3

**Constraints:**

- `1 <= n <= 200`
- `n == isConnected.length`
- `n == isConnected[i].length`
- `isConnected[i][j]` is `1` or `0`.
- `isConnected[i][i] == 1`
- `isConnected[i][j] == isConnected[j][i]`

## My Solution

**JavaScript**

```js
const findCircleNum = (isConnected) => {
  let numProvinces = 0;
  const visited = new Set();

  const dfs = (city) => {
    for (let neighbor = 0; neighbor < isConnected.length; ++neighbor) {
      if (isConnected[city][neighbor] === 1 && !visited.has(neighbor)) {
        visited.add(neighbor);
        dfs(neighbor);
      }
    }
  };

  for (let city = 0; city < isConnected.length; ++city) {
    if (!visited.has(city)) {
      visited.add(city);
      dfs(city);
      numProvinces++;
    }
  }

  return numProvinces;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N^2)          | O(N)             |

```js
const findCircleNum = (isConnected) => {
  let provinceCount = 0;
  const visited = new Set();

  // Returns true if this city discovers a new, unvisited province.
  const exploreCity = (city) => {
    if (visited.has(city)) return false;

    visited.add(city);

    // Recursively visit all connected neighbors in this same province.
    for (let neighbor = 0; neighbor < isConnected.length; ++neighbor) {
      if (isConnected[city][neighbor] === 1 && !visited.has(neighbor)) {
        exploreCity(neighbor);
      }
    }

    // Returns true if we successfully started at a city that was not visited.
    // THis means this city served as an entry point to a new, uncounted province.
    return true;
  };

  // Explore each city. If it returns true, it was part of a new province
  for (let city = 0; city < isConnected.length; ++city) {
    if (exploreCity(city)) {
      provinceCount++;
    }
  }

  return provinceCount;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N^2)          | O(N)             |
