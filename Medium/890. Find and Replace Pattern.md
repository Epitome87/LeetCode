# [890. Find and Replace Pattern](https://leetcode.com/problems/find-and-replace-pattern)

## Description

Given a list of strings `words` and a string `pattern`, return _a list of_ `words[i]` _that match_ `pattern`. You may return the answer in **any order**.

A word matches the pattern if there exists a permutation of letters `p` so that after replacing every letter `x` in the pattern with `p(x)`, we get the desired word.

Recall that a permutation of letters is a bijection from letters to letters: every letter maps to another letter, and no two letters map to the same letter.

**Example 1:**

**Input:** words = ["abc","deq","mee","aqq","dkd","ccc"], pattern = "abb"  
**Output:** ["mee","aqq"]  
**Explanation:** "mee" matches the pattern because there is a permutation {a -> m, b -> e, ...}.  
"ccc" does not match the pattern because {a -> c, b -> c, ...} is not a permutation, since a and b map to the same letter.

**Example 2:**

**Input:** words = ["a","b","c"], pattern = "a"  
**Output:** ["a","b","c"]

**Constraints:**

- `1 <= pattern.length <= 20`
- `1 <= words.length <= 50`
- `words[i].length == pattern.length`
- `pattern` and `words[i]` are lowercase English letters.

## My Solution

**JavaScript**

```js
const findAndReplacePattern = (words, pattern) => {
  const result = [];
  const patternSignature = getSignature(pattern);

  for (const word of words) {
    if (getSignature(word) === patternSignature) {
      result.push(word);
    }
  }

  return result;
};

const getSignature = (str) => {
  const firstSeen = Array(26).fill(-1);
  let signature = '';

  for (let i = 0; i < str.length; ++i) {
    const charCode = str.charCodeAt(i) - 97; // 'a' => 97

    // Only update if we haven't seen this character yet
    if (firstSeen[charCode] === -1) {
      firstSeen[charCode] = i;
    }

    signature += firstSeen[charCode] + ',';
  }

  return signature;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(M \* N)       | O(N)             |

```js
const findAndReplacePattern = (words, pattern) => {
  const result = [];

  for (const word of words) {
    if (matchesPattern(word, pattern)) {
      result.push(word);
    }
  }

  return result;
};

const matchesPattern = (word, pattern) => {
  for (let i = 0; i < word.length; ++i) {
    if (word.indexOf(word[i]) !== pattern.indexOf(pattern[i])) {
      return false;
    }
  }

  return true;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(M \* N^2)     | O(1)             |
