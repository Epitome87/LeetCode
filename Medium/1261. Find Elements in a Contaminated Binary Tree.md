# [1261. Find Elements in a Contaminated Binary Tree](https://leetcode.com/problems/find-elements-in-a-contaminated-binary-tree)

## Description

Given a binary tree with the following rules:

1.  `root.val == 0`
2.  For any `treeNode`:
    1.  If `treeNode.val` has a value `x` and `treeNode.left != null`, then `treeNode.left.val == 2 * x + 1`
    2.  If `treeNode.val` has a value `x` and `treeNode.right != null`, then `treeNode.right.val == 2 * x + 2`

Now the binary tree is contaminated, which means all `treeNode.val` have been changed to `-1`.

Implement the `FindElements` class:

- `FindElements(TreeNode* root)` Initializes the object with a contaminated binary tree and recovers it.
- `bool find(int target)` Returns `true` if the `target` value exists in the recovered binary tree.

**Constraints:**

- `TreeNode.val == -1`
- The height of the binary tree is less than or equal to `20`
- The total number of nodes is between `[1, 10^4]`
- Total calls of `find()` is between `[1, 10^4]`
- `0 <= target <= 10^6`

## My Solution

**JavaScript**

```js
/* Approach: Using O(1) space, but log(target) time complexity. 
Since the root is 0, left child is 2x + 1, and right cild is 2x + 2, if we add 1 
to the value of every node, we can change the formula to become: Root: 0, 
left child: 2x, right child: 2x + 1. Now the binary representation of target + 1 gives
the exact path from the root to the target. Example target = 5. (5 + 1) = 6, in binary is 110.
After ignoring the leading 1 (it being the root), we observe every bit. If it's 0, we visit the left
child, if it's 1 we visit the right. If we traverse the to the target without hitting null, the target exists. */
class FindElements {
  constructor(root) {
    this.root = root;
  }

  find(target) {
    // Find the binary representation of target + 1
    const path = (target + 1).toString(2);
    let current = this.root;

    // Start at i = 1 to skip the leading '1' (the root)
    for (let i = 1; i < path.length; ++i) {
      if (!current) return false;
      if (path[i] === '0') current = current.left;
      else current = current.right;
    }

    // We found the target if we never reached a null value
    return current !== null;
  }
}
```

| Time Complexity                  | Space Complexity |
| -------------------------------- | ---------------- |
| O(1) constructor, O(Log(T)) find | O(Log(T))        |

```js
class FindElements {
  constructor(root) {
    this.set = new Set();
    this.dfs(root, 0);
  }

  dfs(node, val) {
    if (!node) return null;

    // Recover this node to the value we passed
    node.val = val;
    this.set.add(val);

    // Recursively recover children nodes
    this.dfs(node.left, 2 * val + 1);
    this.dfs(node.right, 2 * val + 2);
  }

  find(target) {
    return this.set.has(target);
  }
}
```

| Time Complexity                 | Space Complexity |
| ------------------------------- | ---------------- |
| O(N) constructor/dfs, O(1) find | O(N)             |
