# [1726. Tuple with Same Product](https://leetcode.com/problems/tuple-with-same-product)

## Description

Given an array `nums` of **distinct** positive integers, return _the number of tuples_ `(a, b, c, d)` _such that_ `a * b = c * d` _where_ `a`_,_ `b`_,_ `c`_, and_ `d` _are elements of_ `nums`_, and_ `a != b != c != d`_._

**Example 1:**

**Input:** nums = \[2,3,4,6\]  
**Output:** 8  
**Explanation:** There are 8 valid tuples:  
(2,6,3,4) , (2,6,4,3) , (6,2,3,4) , (6,2,4,3)  
(3,4,2,6) , (4,3,2,6) , (3,4,6,2) , (4,3,6,2)

**Example 2:**

**Input:** nums = \[1,2,4,5,10\]  
**Output:** 16  
**Explanation:** There are 16 valid tuples:  
(1,10,2,5) , (1,10,5,2) , (10,1,2,5) , (10,1,5,2)  
(2,5,1,10) , (2,5,10,1) , (5,2,1,10) , (5,2,10,1)  
(2,10,4,5) , (2,10,5,4) , (10,2,4,5) , (10,2,5,4)  
(4,5,2,10) , (4,5,10,2) , (5,4,2,10) , (5,4,10,2)

**Constraints:**

- `1 <= nums.length <= 1000`
- `1 <= nums[i] <= 10^4`
- All elements in `nums` are **distinct**.

## My Solution

**JavaScript**

```js
// Approach: Count the frequency of each product, and use that frequency to help us calculate the total number
// of tuples with the same product. Note that this approach only works due to the constraint that all numbers are unique!
// If it weren't for that constraint, we could not assume that frequency correlates perfectly to the number of tuples, as some
// frequencies may involve the same number twice, i.e we could not guarantee (a * b = c * d) consisted of all different numbers.
const tupleSameProduct = (nums) => {
  let result = 0;
  const productCount = new Map();

  for (let i = 0; i < nums.length; ++i) {
    for (let j = i + 1; j < nums.length; ++j) {
      const product = nums[i] * nums[j];

      // We can pair this frequency with ALL previous occurrences of it
      // And note each occurrence has 8 tuple arrangements, i.e (p1 * p2 = q1 * q2, p2 * p1 = q1 * q2, etc)
      result += (productCount.get(product) || 0) * 8;

      // Update the frequency of this product by 1
      productCount.set(product, productCount.get(product) + 1 || 1);
    }
  }

  // We could also do 8 x Combination(f, 2) after fully updating the productCount, i.e
  // 8 * f(f - 1) / 2 => 4 * f(f - 1)
  // for (const count of productCount.values()) {
  //     // Only calculate if the product appeared at least twice
  //     if (count > 1) result += 4 * f * (f - 1);
  // }

  return result;
};
```
