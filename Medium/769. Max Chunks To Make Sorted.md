# [769. Max Chunks To Make Sorted](https://leetcode.com/problems/max-chunks-to-make-sorted)

## Description

You are given an integer array `arr` of length `n` that represents a permutation of the integers in the range `[0, n - 1]`.

We split `arr` into some number of **chunks** (i.e., partitions), and individually sort each chunk. After concatenating them, the result should equal the sorted array.

Return _the largest number of chunks we can make to sort the array_.

**Example 1:**

**Input:** arr = [4,3,2,1,0]  
**Output:** 1  
**Explanation:**  
Splitting into two or more chunks will not return the required result.  
For example, splitting into [4, 3], [2, 1, 0] will result in [3, 4, 0, 1, 2], which isn't sorted.

**Example 2:**

**Input:** arr = [1,0,2,3,4]  
**Output:** 4  
**Explanation:**  
We can split into two chunks, such as [1, 0], [2, 3, 4].  
However, splitting into [1, 0], [2], [3], [4] is the highest number of chunks possible.

**Constraints:**

- `n == arr.length`
- `1 <= n <= 10`
- `0 <= arr[i] < n`
- All the elements of `arr` are **unique**.

## My Solution

**JavaScript**

```js
const maxChunksToSorted = (arr) => {
  let result = 0;
  let maxSoFar = 0;

  for (let i = 0; i < arr.length; ++i) {
    maxSoFar = Math.max(maxSoFar, arr[i]);
    if (i === maxSoFar) result++;
  }

  return result;
};
```

```js
// Approach: Simulating the process. We start at the first element, noting its value.
// To fit that value in a chunk, that value must be placed at index = value in the array.
// Therefore its right boundary must extend to at least index = value. While we check this
// window, if we find even larger values, we have to extend the boundary further. Once the
// current boundary is reached, that means we have collected the appropriate range and have
// gained a new, smallest chunk.
const maxChunksToSorted = (arr) => {
  let chunks = 0;
  let i = 0; // Outer pointer for the start of the current chunk

  while (i < arr.length) {
    // Grab the initial value and determine our tentative right boundary
    let rightBoundary = arr[i];
    let j = i;

    // Scan across the range from our start pointer up to our current required boundary.
    // As we scan, if we encounter a larger number, our required boundary expands!
    while (j <= rightBoundary) {
      rightBoundary = Math.max(rightBoundary, arr[j]);
      j++;
    }

    // Once our scan successfully covers all trapped elements without needing further expansion,
    // we have completed one valid chunk!
    chunks++;

    // Move our outer pointer to the start of the next chunk (right after the boundary)
    i = rightBoundary + 1;
  }

  return chunks;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N)            | O(1)             |
