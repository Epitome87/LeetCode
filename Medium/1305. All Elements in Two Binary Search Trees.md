# [1305. All Elements in Two Binary Search Trees](https://leetcode.com/problems/all-elements-in-two-binary-search-trees)

## Description

Given two binary search trees `root1` and `root2`, return _a list containing all the integers from both trees sorted in **ascending** order_.

**Example 1:**

![](https://assets.leetcode.com/uploads/2019/12/18/q2-e1.png)

**Input:** root1 = [2,1,4], root2 = [1,0,3]  
**Output:** [0,1,1,2,3,4]

**Example 2:**

![](https://assets.leetcode.com/uploads/2019/12/18/q2-e5-.png)

**Input:** root1 = [1,null,8], root2 = [8,1]  
**Output:** [1,1,8,8]

**Constraints:**

- The number of nodes in each tree is in the range `[0, 5000]`.
- `-10^5 <= Node.val <= 10^5`

## My Solution

**JavaScript**

```js
// Approach: Using iterative inorder traversal so we only store the nodes along the
// current tree1 and tree2 path at any given time.
const getAllElements = (root1, root2) => {
  const result = [];
  const stack1 = [];
  const stack2 = [];

  // As long as there are unvisited nodes in either tree or stack
  while (root1 !== null || root2 !== null || stack1.length || stack2.length) {
    // Traverse down to the leftmost node of tree 1
    while (root1) {
      stack1.push(root1);
      root1 = root1.left;
    }

    // Traverse down to the leftmost node of tree 2
    while (root2) {
      stack2.push(root2);
      root2 = root2.left;
    }

    // Compare the top of both stacks, which are the current smallest values available.
    // If stack2 is empty, or stack1's top is <= stack2's top, process stack1
    if (stack2.length === 0 || (stack1.length && stack1.at(-1).val <= stack2.at(-1).val)) {
      root1 = stack1.pop();
      result.push(root1.val);
      root1 = root1.right;
    } else {
      root2 = stack2.pop();
      result.push(root2.val);
      root2 = root2.right;
    }
  }

  return result;
};
```

| Time Complexity | Space Complexity     |
| --------------- | -------------------- |
| O(N + M)        | O(Height1 + Height2) |

```js
// Approach: Perform a typical inorder tree traversal, once on each root.
// After storing the traversal (in ascending order, since its inorder on a BST)
// of each tree in a separate array, merge the arrays into a single result.
const getAllElements = (root1, root2) => {
  const result = [];
  const arr1 = [];
  const arr2 = [];

  // Helper inorder traversal function. It also pushes node values
  // to the input array along the way.
  const inorder = (root, arr) => {
    if (!root) return;
    inorder(root.left, arr);
    arr.push(root.val);
    inorder(root.right, arr);
  };

  // Perform an inorder traversal on both trees, storing their results in separate arrays
  inorder(root1, arr1);
  inorder(root2, arr2);

  // Merge the two sorted arrays into one sorted array
  let idx1 = 0;
  let idx2 = 0;

  while (idx1 < arr1.length && idx2 < arr2.length) {
    if (arr1[idx1] <= arr2[idx2]) {
      result.push(arr1[idx1]);
      idx1++;
    } else {
      result.push(arr2[idx2]);
      idx2++;
    }
  }

  // Collect remaining elements from the unfinished array
  while (idx1 < arr1.length) result.push(arr1[idx1++]);
  while (idx2 < arr2.length) result.push(arr2[idx2++]);

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N + M)        | O(N + M)         |
