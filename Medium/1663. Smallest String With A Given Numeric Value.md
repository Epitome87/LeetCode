# [1663. Smallest String With A Given Numeric Value](https://leetcode.com/problems/smallest-string-with-a-given-numeric-value)

## Description

The **numeric value** of a **lowercase character** is defined as its position `(1-indexed)` in the alphabet, so the numeric value of `a` is `1`, the numeric value of `b` is `2`, the numeric value of `c` is `3`, and so on.

The **numeric value** of a **string** consisting of lowercase characters is defined as the sum of its characters' numeric values. For example, the numeric value of the string `"abe"` is equal to `1 + 2 + 5 = 8`.

You are given two integers `n` and `k`. Return _the **lexicographically smallest string** with **length** equal to `n` and **numeric value** equal to `k`._

Note that a string `x` is lexicographically smaller than string `y` if `x` comes before `y` in dictionary order, that is, either `x` is a prefix of `y`, or if `i` is the first position such that `x[i] != y[i]`, then `x[i]` comes before `y[i]` in alphabetic order.

**Example 1:**

**Input:** n = 3, k = 27  
**Output:** "aay"  
**Explanation:** The numeric value of the string is 1 + 1 + 25 = 27, and it is the smallest string with such a value and length equal to 3.

**Example 2:**

**Input:** n = 5, k = 73  
**Output:** "aaszz"

**Constraints:**

- `1 <= n <= 10^5`
- `n <= k <= 26 * n`

## My Solution

**JavaScript**

```js
// Approach: Using Math! To calculate the string only requires O(1) time. Unfortunately, construction
// of the string result will always require at least O(N) time.
const getSmallestString = (n, k) => {
  // What's the budget after we filling the string with all 'a'?
  let remainingBudget = k - n;

  // How many 'z' can we use? (Going from 'a' to 'z' costs 25)
  const zCount = Math.floor(remainingBudget / 25);

  // What character do we use as an intermediate character?
  const leftover = remainingBudget % 25;

  // How many 'a' remain at the front after accounting for the z's and intermediate char?
  const aCount = n - zCount - (leftover > 0 ? 1 : 0);

  // Our result begins with that amount of 'a'
  let result = 'a'.repeat(aCount);

  // We then add the intermediate character (if one was needed)
  if (leftover > 0) {
    result += String.fromCharCode(97 + leftover);
  }

  // And finally, we add all our 'z' characters
  result += 'z'.repeat(zCount);

  return result;
};
```

| --------------- | ---------------- |
| O(N)            | O(1)             |

```js
// Approach: Start with a result full of n 'a' characters. We want to keep as many
// in the front as possible. So start from the end and maximize the character as much
// as possible, going inward if we still have not reached k.
const getSmallestString = (n, k) => {
  const result = Array(n).fill('a');

  // Reduce k by 1 for each 'a' initially selected
  k -= n;

  // Start at the last index
  let i = n - 1;

  while (k > 0) {
    // Try to place the largest char possible (from 'z' to 'b')
    for (let j = 26; j >= 1; --j) {
      // Cost to upgrade from an 'a'
      const upgradeCost = j - 1;

      if (upgradeCost <= k) {
        // Replace the 'a' at this index with new maximized char
        result[i] = String.fromCharCode(97 + j - 1);
        // Subtract the cost of this choice from k
        k -= upgradeCost;
        // Move onto the character to the left
        i--;
        break;
      }
    }
  }

  return result.join('');
};
```

| --------------- | ---------------- |
| O(N)            | O(1)             |

```js
// Approach: Time: O(N * 26) with modern JS string optimization, but N^2 theoretically. We want to select as many lexicographically smaller letters as possible,
// while still ensuring we can reach a numeric value of k. While we haven't chosen n
// characters, iterate from choice a to z, seeing which one can be picked while still ensuring
// the remaining n - 1 choices can reach a value of k - choice.
const getSmallestString = (n, k) => {
  let result = '';

  while (n > 0) {
    // Can we select an 'a' and still reach k in (n - 1) characters?
    // If not, can we select a 'b' and still reach k in (n - 1) characters?
    for (let i = 1; i <= 26; ++i) {
      if (k - i <= (n - 1) * 26) {
        result += String.fromCharCode(97 + (i - 1));
        n--;
        k -= i;
        break;
      }
    }
  }

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N^2)          | O(1)             |
