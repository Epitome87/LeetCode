# [2047. Number of Valid Words in a Sentence](https://leetcode.com/problems/number-of-valid-words-in-a-sentence)

## Description

A sentence consists of lowercase letters (`'a'` to `'z'`), digits (`'0'` to `'9'`), hyphens (`'-'`), punctuation marks (`'!'`, `'.'`, and `','`), and spaces (`' '`) only. Each sentence can be broken down into **one or more tokens** separated by one or more spaces `' '`.

A token is a valid word if **all three** of the following are true:

- It only contains lowercase letters, hyphens, and/or punctuation (**no** digits).
- There is **at most one** hyphen `'-'`. If present, it **must** be surrounded by lowercase characters (`"a-b"` is valid, but `"-ab"` and `"ab-"` are not valid).
- There is **at most one** punctuation mark. If present, it **must** be at the **end** of the token (`"ab,"`, `"cd!"`, and `"."` are valid, but `"a!b"` and `"c.,"` are not valid).

Examples of valid words include `"a-b."`, `"afad"`, `"ba-c"`, `"a!"`, and `"!"`.

Given a string `sentence`, return _the **number** of valid words in_ `sentence`.

**Example 1:**

**Input:** sentence = "cat and dog"  
**Output:** 3  
**Explanation:** The valid words in the sentence are "cat", "and", and "dog".

**Example 2:**

**Input:** sentence = "!this 1-s b8d!"  
**Output:** 0  
**Explanation:** There are no valid words in the sentence.  
"!this" is invalid because it starts with a punctuation mark.  
"1-s" and "b8d" are invalid because they contain digits.

**Example 3:**

**Input:** sentence = "alice and bob are playing stone-game10"  
**Output:** 5  
**Explanation:** The valid words in the sentence are "alice", "and", "bob", "are", and "playing".  
"stone-game10" is invalid because it contains digits.

**Constraints:**

- `1 <= sentence.length <= 1000`
- `sentence` only contains lowercase English letters, digits, `' '`, `'-'`, `'!'`, `'.'`, and `','`.
- There will be at least `1` token.

## My Solution

**JavaScript**

```js
// Approach: Avoiding String.split to achieve O(1) space
const countValidWords = (sentence) => {
  let result = 0;
  let n = sentence.length;
  let i = 0;

  while (i < n) {
    // 1. Skip leading/multiple spaces
    while (i < n && sentence[i] === ' ') {
      i++;
    }
    if (i >= n) break;

    // 2. Find the start and end indices of the current word
    let start = i;
    while (i < n && sentence[i] !== ' ') {
      i++;
    }
    let end = i; // end is exclusive

    // 3. Validate the word in-place using its indices
    if (isValidWord(sentence, start, end)) {
      result++;
    }
  }

  return result;
};

const isValidWord = (str, start, end) => {
  let numHyphens = 0;

  for (let j = start; j < end; ++j) {
    const char = str[j];

    // Lowercase letters are valid
    if (char >= 'a' && char <= 'z') continue;

    // Digits are never valid
    if (char >= '0' && char <= '9') return false;

    // Hyphen rules
    if (char === '-') {
      numHyphens++;
      // More than one hyphen, or hyphen at the very start/end is invalid
      if (numHyphens > 1 || j === start || j === end - 1) return false;
      // Must be surrounded by lowercase letters
      if (str[j - 1] < 'a' || str[j - 1] > 'z' || str[j + 1] < 'a' || str[j + 1] > 'z') {
        return false;
      }
    }
    // Punctuation rules (., !)
    else {
      // Punctuation must only appear as the last character of the word
      if (j !== end - 1) return false;
    }
  }

  return true;
};
```

```js
// Approach: Using Regex
// ^([a-z]+ matches one or more lowercase characters, requiring the word to start with one
// (-[a-z]+)? matches the case where if a hyphen exists, it is surrounded by lowercase letters
// [.,!]? handles the punctuation rule: If one is present, it is at the end
// |[.,!]$ is a second scenario for a valid word. It matches a single punctuation mark, at the end of sentence
const countValidWords = (sentence) =>
  sentence.split(' ').filter((word) => /^([a-z]+(-[a-z]+)?[.,!]?|[.,!])$/.test(word)).length;
```

```js
const countValidWords = (sentence) => {
  const isValid = (word) => {
    const isDigit = (char) => char >= '0' && char <= '9';
    const isAlpha = (char) => char >= 'a' && char <= 'z';
    let numHyphens = 0;
    let numPunctuation = 0;

    for (let i = 0; i < word.length; ++i) {
      const char = word[i];

      // Lowercase letters are fine and have no special rules
      if (isAlpha(char)) continue;

      // No digits
      if (isDigit(char)) return false;

      // Hyphens must only occur once, and be surrounded by lowercase letters
      if (char === '-') {
        numHyphens++;
        if (numHyphens > 1) return false;
        if (i - 1 < 0 || !isAlpha(word[i - 1]) || i + 1 >= word.length || !isAlpha(word[i + 1])) return false;
      }
      // Finally, remaining chars (punctuation) must be the last character
      else if (i !== word.length - 1) return false;
    }

    return true;
  };

  let result = 0;

  for (const word of sentence.split(' ')) {
    if (word !== '' && isValid(word)) ++result;
  }

  return result;
};
```
