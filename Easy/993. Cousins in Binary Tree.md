# [993. Cousins in Binary Tree](https://leetcode.com/problems/cousins-in-binary-tree)

## Description

Given the `root` of a binary tree with unique values and the values of two different nodes of the tree `x` and `y`, return `true` _if the nodes corresponding to the values_ `x` _and_ `y` _in the tree are **cousins**, or_ `false` _otherwise._

Two nodes of a binary tree are **cousins** if they have the same depth with different parents.

Note that in a binary tree, the root node is at the depth `0`, and children of each depth `k` node are at the depth `k + 1`.

**Example 1:**

![](https://assets.leetcode.com/uploads/2019/02/12/q1248-01.png)

**Input:** root = \[1,2,3,4\], x = 4, y = 3  
**Output:** false

**Example 2:**

![](https://assets.leetcode.com/uploads/2019/02/12/q1248-02.png)

**Input:** root = \[1,2,3,null,4,null,5\], x = 5, y = 4  
**Output:** true

**Example 3:**

![](https://assets.leetcode.com/uploads/2019/02/13/q1248-03.png)

**Input:** root = \[1,2,3,null,4\], x = 2, y = 3  
**Output:** false

**Constraints:**

- The number of nodes in the tree is in the range `[2, 100]`.
- `1 <= Node.val <= 100`
- Each node has a **unique** value.
- `x != y`
- `x` and `y` are exist in the tree.

## My Solution

**JavaScript**

```js
// Approach: Brute-Force
const isCousins = (root, x, y) => {
  let xParent = null;
  let yParent = null;
  let xDepth = -1;
  let yDepth = -1;

  // Helper traversal method. Calculates depths and parents along the way.
  const depthAndParent = (root, x, y, depth, parent) => {
    if (!root) return;

    if (root.val === x) {
      xParent = parent;
      xDepth = depth;
    } else if (root.val === y) {
      yParent = parent;
      yDepth = depth;
    } else if (xDepth === -1 || yDepth === -1) {
      // Only keep recursing if there is still a depth/parent to discover
      depthAndParent(root.left, x, y, depth + 1, root);
      depthAndParent(root.right, x, y, depth + 1, root);
    }
  };

  // Begin DFS and calculate the depth of x and y, along with their parent
  depthAndParent(root, x, y, 0, null);

  // Return true if the two depths are the same, but their parents differ
  return xDepth === yDepth && xParent !== yParent;
};
```
