# [2089. Find Target Indices After Sorting Array](https://leetcode.com/problems/find-target-indices-after-sorting-array)

## Description

You are given a **0-indexed** integer array `nums` and a target element `target`.

A **target index** is an index `i` such that `nums[i] == target`.

Return _a list of the target indices of_ `nums` after _sorting_ `nums` _in **non-decreasing** order_. If there are no target indices, return _an **empty** list_. The returned list must be sorted in **increasing** order.

**Example 1:**

**Input:** nums = [1,2,5,2,3], target = 2  
**Output:** [1,2]  
**Explanation:** After sorting, nums is [1,**2**,**2**,3,5].  
The indices where nums[i] == 2 are 1 and 2.

**Example 2:**

**Input:** nums = [1,2,5,2,3], target = 3  
**Output:** [3]  
**Explanation:** After sorting, nums is [1,2,2,**3**,5].  
The index where nums[i] == 3 is 3.

**Example 3:**

**Input:** nums = [1,2,5,2,3], target = 5  
**Output:** [4]  
**Explanation:** After sorting, nums is [1,2,2,3,**5**].  
The index where nums[i] == 5 is 4.

**Constraints:**

- `1 <= nums.length <= 100`
- `1 <= nums[i], target <= 100`

## My Solution

**JavaScript**

```js
// Approach: Without sorting. Simply count how many numbers are less than the target.
// This tracks which index the matches will start at. Use a second counter to track how
// many instances of target there are. The result can be constructed with this information!
const targetIndices = (nums, target) => {
  const result = [];
  let startingIdx = 0; // Tracks which index in "sorted" array the target values start at
  let numMatches = 0; // Tracks how many nums match target

  for (let i = 0; i < nums.length; ++i) {
    if (nums[i] < target) startingIdx++;
    else if (nums[i] === target) numMatches++;
  }

  for (let i = 0; i < numMatches; ++i) {
    result.push(startingIdx);
    startingIdx++;
  }

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N)            | O(1)             |

```js
// Approach: Directly simulating the process by sorting
const targetIndices = (nums, target) => {
  const result = [];
  const sorted = nums.toSorted((a, b) => a - b);

  for (let i = 0; i < sorted.length; ++i) {
    if (sorted[i] === target) result.push(i);
  }

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N \* Log(N))  | O(N)             |

```js
// Approach: Using sorting and JavaScript built-in methods.
const targetIndices = (nums, target) =>
  [...nums].toSorted((a, b) => a - b).reduce((acc, cur, idx) => (cur === target ? acc.concat(idx) : acc), []);
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N \* Log(N))  | O(N)             |
