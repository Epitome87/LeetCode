# [4006. Count Valid Prefixes](https://leetcode.com/problems/count-valid-prefixes)

## Description

You are given a binary string `s`.

A prefix of `s` is considered **valid** if its characters can be rearranged to form an **alternating** string.

Return the number of valid prefixes of `s`.

A string is considered **alternating** if no two adjacent characters are equal.

**Example 1:**

**Input:** s = "00101"  
**Output:** 3  
**Explanation:**  
The valid prefixes are:

- `"0"`: It is already an alternating string.
- `"001"`: It can be rearranged into `"010"`, which is an alternating string.
- `"00101"`: It can be rearranged into `"01010"`, which is an alternating string.

Thus, the answer is 3.

**Example 2:**

**Input:** s = "101"  
**Output:** 3  
**Explanation:**  
All prefixes of `s = "101"` are already alternating strings. Thus, the answer is 3.

## My Solution

**JavaScript**

```js
// Approach: Maintain a "balance" variable, where positive values indicate more 1's than 0's, and
// negative values represent more 0's than 1's in the current prefix. Note that a prefix can only
// alternate if the difference between the number of 0's and 1's is zero or one. When the difference is 0,
// we can alternate like "0101", and when the difference is 1 we can alternate like "010". Observe that a
// difference of 2 or more cannot be alternated, e.g "0100" (where the "balance" is -2).
const countValidPrefixes = (s) => {
  let result = 0;
  let balance = 0;

  for (const bit of s) {
    if (bit === '1') balance++;
    else balance--;
    if (Math.abs(balance) <= 1) result++;
  }

  return result;
};
```

| --------------- | ---------------- |
| O(N)            | O(1)             |
