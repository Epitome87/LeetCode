# [3582. Generate Tag for Video Caption](https://leetcode.com/problems/generate-tag-for-video-caption)

## Description

You are given a string `caption` representing the caption for a video.

The following actions must be performed **in order** to generate a **valid tag** for the video:

1.  **Combine all words** in the string into a single _camelCase string_ prefixed with `'#'`. A _camelCase string_ is one where the first letter of all words _except_ the first one is capitalized. All characters after the first character in **each** word must be lowercase.
2.  **Remove** all characters that are not an English letter, **except** the first `'#'`.
3.  **Truncate** the result to a maximum of 100 characters.

Return the **tag** after performing the actions on `caption`.

**Example 1:**

**Input:** caption = "Leetcode daily streak achieved"  
**Output:** "#leetcodeDailyStreakAchieved"  
**Explanation:** The first letter for all words except `"leetcode"` should be capitalized.

**Example 2:**

**Input:** caption = "can I Go There"  
**Output:** "#canIGoThere"  
**Explanation:** The first letter for all words except `"can"` should be capitalized.

**Example 3:**

**Input:** caption = "hhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhh"  
**Output:** "#hhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhhh"  
**Explanation:** Since the first word has length 101, we need to truncate the last two letters from the word.

**Constraints:**

- `1 <= caption.length <= 150`
- `caption` consists only of English letters and `' '`.

## My Solution

**JavaScript**

```js
// Approach: Observe that every char should be lowercase, except the first letter of a subsequent word.
// This allows us to trim the per-character logic quite a bit.
const generateTag = (caption) => {
  // Each resulting tag must start with a hash
  let result = '#';

  for (let i = 0; i < caption.length && result.length < 100; ++i) {
    // Skip spaces
    if (caption[i] === ' ') continue;

    // Uppercase if a char follows a space and it's not the first character added, otherwise lowercase it
    result += caption[i - 1] === ' ' && result.length > 1 ? caption[i].toUpperCase() : caption[i].toLowerCase();
  }

  return result;
};
```

```js
// Approach: Avoiding JavaScript built-in methods. For each character, check if a space
// occurred before it. If so, this is the start of a new word. Determine if it's the first
// or subsequent word, converting it to lowercase or uppercase appropriately. Note this only
// works properly due the the input constraint that only a-z, A-Z and spaces are allowed to
// be provided. It will not automatically remove special characters.
const generateTag = (caption) => {
  // Each resulting tag must start with a hash
  let result = '#';

  for (let i = 0; i < caption.length; ++i) {
    // Skip spaces
    if (caption[i] === ' ') continue;

    // Is this the first non-space character found? Lowercase it.
    if (result.length === 1) result += caption[i].toLowerCase();
    // Start of new word (but not the first word?)
    else if (caption[i - 1] === ' ') result += caption[i].toUpperCase();
    // Else this isn't the first character of a word; lowercase it
    else result += caption[i].toLowerCase();

    // Return early if we've reached the limit
    if (result.length >= 100) return result;
  }

  return result;
};
```

| Time Complexity | Space Complexity |
| --------------- | ---------------- |
| O(N)            | O(1)             |

```js
// Approach: Utilizing JavaScript built-in functions
const generateTag = (caption) => {
  // Separate string into groups of only English letters a-z
  const words = caption.match(/[a-zA-Z]+/g) || [];

  // Convert each word to camel case
  const camel = words.map((w, i) => (i ? w[0].toUpperCase() + w.slice(1).toLowerCase() : w.toLowerCase()));

  // Finally, prepend the result with '#' and return only the first 100 characters
  return ('#' + camel.join('')).slice(0, 100);
};
```
