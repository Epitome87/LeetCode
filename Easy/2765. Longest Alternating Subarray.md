# [2765. Longest Alternating Subarray](https://leetcode.com/problems/longest-alternating-subarray)

## Description

You are given a **0-indexed** integer array `nums`. A subarray `s` of length `m` is called **alternating** if:

- `m` is greater than `1`.
- `s1 = s0 + 1`.
- The **0-indexed** subarray `s` looks like `[s0, s1, s0, s1,...,s(m-1) % 2]`. In other words, `s1 - s0 = 1`, `s2 - s1 = -1`, `s3 - s2 = 1`, `s4 - s3 = -1`, and so on up to `s[m - 1] - s[m - 2] = (-1)m`.

Return _the maximum length of all **alternating** subarrays present in_ `nums` _or_ `-1` _if no such subarray exists._

A subarray is a contiguous **non-empty** sequence of elements within an array.

**Example 1:**

**Input:** nums = \[2,3,4,3,4\]  
**Output:** 4  
**Explanation:**  
The alternating subarrays are `[2, 3]`, `[3,4]`, `[3,4,3]`, and `[3,4,3,4]`. The longest of these is `[3,4,3,4]`, which is of length 4.

**Example 2:**

**Input:** nums = \[4,5,6\]  
**Output:** 2  
**Explanation:**  
`[4,5]` and `[5,6]` are the only two alternating subarrays. They are both of length 2.

**Constraints:**

- `2 <= nums.length <= 100`
- `1 <= nums[i] <= 10^4`

## My Solution

**JavaScript**

```js
const alternatingSubarray = (nums) => {
  let result = -1;
  let count = 1;
  let expectedDiff = 1;

  for (let i = 1; i < nums.length; ++i) {
    // Does alternating streak continue?
    if (nums[i] - nums[i - 1] === expectedDiff) {
      count++;
      expectedDiff *= -1; // Flip sign for next iteration
      result = Math.max(result, count);
    }
    // Streak broke, but this pair starts a new alternating subarray
    else if (nums[i] - nums[i - 1] === 1) {
      count = 2;
      expectedDiff = -1;
    }
    // Streak broke completely
    else {
      count = 1;
      expectedDiff = 1;
    }
  }

  return result;
};
```
