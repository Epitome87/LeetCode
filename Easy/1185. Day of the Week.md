# [1185. Day of the Week](https://leetcode.com/problems/day-of-the-week)

## Description

Given a date, return the corresponding day of the week for that date.

The input is given as three integers representing the `day`, `month` and `year` respectively.

Return the answer as one of the following values `{"Sunday", "Monday", "Tuesday", "Wednesday", "Thursday", "Friday", "Saturday"}`.

**Note:** January 1, 1971 was a Friday.

**Example 1:**

**Input:** day = 31, month = 8, year = 2019  
**Output:** "Saturday"

**Example 2:**

**Input:** day = 18, month = 7, year = 1999  
**Output:** "Sunday"

**Example 3:**

**Input:** day = 15, month = 8, year = 1993  
**Output:** "Sunday"

**Constraints:**

- The given dates are valid dates between the years `1971` and `2100`.

## My Solution

**JavaScript**

```js
// Approach: Knowing that January 1st, 1971 was a a Friday, calculate how many
// days have elapsed since then. Account for leap years by adjusting February's day count.
const dayOfTheWeek = (day, month, year) => {
  const week = ['Sunday', 'Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday', 'Saturday'];
  const isLeapYear = (y) => (y % 4 === 0 && y % 100 !== 0) || y % 400 === 0;
  const daysOfMonth = [31, isLeapYear(year) ? 29 : 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31];
  let elapsedDays = 0;

  // For each year PRIOR to the current year, sum up their day count
  for (let i = 1971; i < year; ++i) {
    if (isLeapYear(i)) elapsedDays += 366;
    else elapsedDays += 365;
  }

  // For each month PRIOR to the current month, sum up their day count
  // Note this will only be months from current year
  for (let i = 0; i < month - 1; ++i) {
    elapsedDays += daysOfMonth[i];
  }

  // Finally, add the count of days from the current month
  elapsedDays += day - 1;

  // Add 5 to elapsed days to account for 1/1/1971 being a Friday
  return week[(elapsedDays + 5) % 7];
};
```
